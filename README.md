# Southampton voyage destinations dashboard

Static MapLibre dashboard prepared for GitHub Pages.

## Publish on GitHub Pages

1. Upload `index.html` and `.nojekyll` to a repository.
2. In **Settings → Pages**, deploy from the repository branch and root folder.
3. The dashboard requires internet access for MapLibre and OpenFreeMap tiles.

## Interpretation

Connections link Southampton as a recorded voyage origin to a recorded voyage destination. They do not reconstruct exact sailing tracks.
